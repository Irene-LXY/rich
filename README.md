# RichMan 大富翁 —— A3 / A17 / A21（初始资金设置 + 破产与土地归还 + 游戏结束判定）

基于《大富翁.pdf》与《大富翁游戏自动化测试JSON接口规范v1.1》开发的 C 语言项目。
本文件夹当前版本已完成：初始资金设置、破产与土地归还、游戏结束判定。
具体功能如下：

- **A3 初始资金设置**：游戏开始前给本局所有玩家发放统一初始资金（1000~50000，默认 10000）；
- **A17 破产与土地归还**：交易/收费使资金低于 0 时宣布破产，名下土地归还系统、恢复为空地，可被重新购买；
- **A21 游戏结束判定**：只剩一名未破产玩家时游戏结束并宣布获胜者。

## 编译运行

### 方式一：MSVC（Visual Studio 2022，Windows）

```bat
build.bat
bin\A3_A17_A21.exe
```

### 方式二：gcc / MinGW / Linux

```bash
make
./bin/A3_A17_A21      # Windows 下为 ./bin/A3_A17_A21.exe
```

### 破产机制演示（A17 / A21，无需交互）

```bat
bin\A3_A17_A21.exe --demo
```

## 操作流程

1. **玩家人数**：仅允许 2~4 人，非法输入说明原因并重输；
2. **角色选择**：玩家1~N 轮流选择不重复的角色（1=钱夫人/Q、2=阿土伯/A、3=孙小美/S、4=金贝贝/J）；
3. **初始资金**：输入 1000~50000 的整数（直接回车 = 默认 10000），确认前显示最终采用数值；确认 Y 后才统一写入所有玩家资产；N 或输入结束则不修改任何玩家资金；
4. **进入第 1 回合**：显示各玩家角色与资金。

## 关键保证

- **初始资金原子写入**：单一数值单次循环写入所有玩家，写入前校验、写入后复核——不存在部分玩家已修改、部分未修改的情况；
- **破产判定**：资金 < 0 才破产（等于 0 不破产）；破产即归还全部土地为空地；只剩一名未破产玩家时游戏结束。
