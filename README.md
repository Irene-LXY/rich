# A2 大富翁（C 语言实现）

基于《大富翁.pdf》与《大富翁游戏自动化测试JSON接口规范v1.1》开发的 C 语言项目。
当前已实现 **游戏开局玩家人数输入与角色选择** 模块。

## 目录结构（标准 C 项目布局）

```
A2/
├── include/            头文件（模块接口声明）
│   ├── character.h     角色模块：角色编号/名称/颜色/地图符号
│   ├── player.h        玩家模块：玩家数据结构与选择校验
│   ├── game.h          游戏模块：游戏创建与第一回合
│   ├── selection.h     选择向导：人数输入、角色选择、确认
│   └── console.h       控制台模块：UTF-8 与 ANSI 颜色初始化
├── src/                源文件（模块实现）
│   ├── character.c
│   ├── player.c
│   ├── game.c
│   ├── selection.c
│   ├── console.c
│   └── main.c          程序入口
├── bin/                二进制文件（编译输出的可执行程序）
├── obj/                编译中间产物（.obj / .o）
├── docs/               设计文档
│   └── 角色选择模块设计说明.md
├── tests/              测试用例
│   └── 角色选择测试用例.md
├── Makefile            gcc / MinGW 构建脚本
├── build.bat           MSVC 一键编译脚本（Windows）
└── README.md
```

## 编译运行

### 方式一：MSVC（Visual Studio 2022，Windows）

```bat
build.bat
bin\A2.exe
```

### 方式二：gcc / MinGW / Linux

```bash
make
./bin/A2      # Windows 下为 ./bin/A2.exe
```

## 已实现需求

- 仅允许 **2~4 名玩家**，人数非法时说明合法范围并要求重新输入；
- 按 **玩家1 ~ 玩家N** 的顺序依次引导选择角色；
- 角色：**1=钱夫人（红/Q）、2=阿土伯（绿/A）、3=孙小美（蓝/S）、4=金贝贝（黄/J）**；
- 每名玩家必须选择一个角色，**同一局内角色不得重复**；
- 已被选择的角色**不再出现在剩余可选项**中；
- 每次选择时显示**当前操作玩家**与**剩余可选角色**；
- 输入不存在的角色、重复角色或非法字符时**说明原因并允许重新选择**；
- **所有玩家完成选择并确认后**才创建游戏并进入第一个回合；
- 选择失败或尚未确认时**不产生任何半初始化的玩家数据**。

详见 `docs/角色选择模块设计说明.md` 与 `tests/角色选择测试用例.md`。
