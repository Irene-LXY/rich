# 帮助模块设计说明（A6）

本文档对应功能点 **A6 帮助命令**：随时打开帮助界面查看完整指令集，Help 命令忽略大小写。
其余模块见《角色选择模块设计说明.md》《初始资金与破产模块设计说明.md》。

## 1. 模块划分

| 模块 | 文件 | 职责 |
|------|------|------|
| help | include/help.h, src/help.c | 帮助界面内容（完整指令集）；HELP 命令忽略大小写的整词匹配 |
| cli  | include/cli.h, src/cli.c     | 指令输入循环——“随时打开帮助”的宿主环境 |
| main | src/main.c                   | 新增 `--help` 直查参数；第 1 回合后进入指令循环 |

## 2. 需求逐条追踪

| 需求 | 实现位置 | 说明 |
|------|----------|------|
| 随时打开帮助界面 | `cli_command_loop()` | 对局指令循环中每次输入都识别 HELP，可重复打开；另支持 `A6.exe --help` 不开局直接查看 |
| Help 命令忽略大小写 | `help_is_help_command()` | 逐字符 `tolower` 比较：help / HELP / Help / hElP 均有效；首尾空格容忍（先 trim） |
| 整词匹配 | `help_is_help_command()` | `helps`、`hel`、`help me` 均不视为 HELP |
| 列出全部命令 | `help_print()` | HELP / ROLL / STEP n / SELL n / BLOCK n / BOMB n / ROBOT / QUERY / QUIT 共 9 条 |
| 每条含用途、参数、简短示例 | `help_print()` | 每条命令含「用途 / 参数 / 示例」三行 |
| 指令内容 | `help_print()` | ROLL＝掷骰子随机行走 1~6 步；STEP n＝遥控骰子指定步数；SELL n＝出售自有房产、售价为投资总成本 2 倍，n 为地图绝对位置；BLOCK n＝前后 10 步内放路障拦截经过玩家、一次有效；BOMB n＝前后 10 步内放炸弹、经过者住院三天；BLOCK/BOMB 的 n 为相对距离、负数为后方；ROBOT＝清扫前方 10 步内道具；QUERY＝显示自家资产；QUIT＝强制退出整局 |
| 不需要完成其他指令功能 | `cli_command_loop()` | ROLL/STEP/SELL/BLOCK/BOMB/ROBOT/QUERY 识别后提示“由对应模块实现”；不会执行骰子/移动/售房/道具/查询逻辑 |
| 其他命令大小写 | `command_name()` + `command_known()` | 按接口规范“命令统一使用大写”，ROLL/STEP/SELL/BLOCK/BOMB/ROBOT/QUERY/QUIT 按大写精确匹配（如 `query` 判为未知命令并建议 HELP）；仅 HELP 忽略大小写 |
| EOF / QUIT 退出演示 | `cli_command_loop()` | EOF 安全退出；QUIT 演示性强制结束（完整功能由对应模块实现） |

## 3. 帮助界面样式

```
======================================================
                  帮助 · 完整指令集
======================================================
命令：HELP
  用途：查看命令帮助——打开本帮助界面，随时查看完整指令集。
  参数：无。
  示例：HELP        （忽略大小写：help / Help / hElP 均可）

命令：ROLL
  用途：掷骰子命令，行走 1~6 步，步数由随机算法产生。
  参数：无。
  示例：ROLL

命令：STEP n
  用途：遥控骰子，按指定步数行走。
  参数：n —— 指定的步数（正整数）。
  示例：STEP 5      （向前移动 5 步）

命令：SELL n
  用途：轮到自己时，出售自己的任意房产，
        出售价格为投资总成本的 2 倍。
  参数：n —— 房产在地图上的绝对位置。
  示例：SELL 23     （出售位于 23 号的房产）

命令：BLOCK n
  用途：将路障放置到离当前位置前后 10 步的任何位置；
        任一玩家经过路障，将被拦截。该道具一次有效。
  参数：n —— 前后的相对距离（-10~10），负数表示后方。
  示例：BLOCK 3（放到前方 3 步）；BLOCK -2（放到后方 2 步）

命令：BOMB n
  用途：将炸弹放置到离当前位置前后 10 步的任何位置；任一玩家
        经过该位置，将被炸伤，送往医院，住院三天。
  参数：n —— 前后的相对距离（-10~10），负数表示后方。
  示例：BOMB 5 （放到前方 5 步）；BOMB -1（放到后方 1 步）

命令：ROBOT
  用途：使用机器人清扫前方路面上 10 步内的任何其他道具，
        如炸弹、路障。
  参数：无。
  示例：ROBOT

命令：QUERY
  用途：显示自家资产。
  参数：无。
  示例：QUERY

命令：QUIT
  用途：强制退出，整局游戏立即结束。
  参数：无。
  示例：QUIT
======================================================
提示：对局进行中可随时输入 HELP 重新打开本帮助界面。
```

## 4. 调用时机（“随时”）

```
main()
  ├─ A6.exe --help  → help_print()              开局前直接查看
  ├─ 角色选择 → 初始资金 → 进入第 1 回合
  └─ cli_command_loop(game)                     对局中每次输入命令时
        └─ 输入 help/HELP/hElP/... → help_print()   随时、可重复打开
```
