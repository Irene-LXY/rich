# A20 中途强制退出

## 正式 Story

作为繁忙玩家，为了随时中止游戏，我希望随时结束游戏。

## 本轮采用的验收口径

- 命令为 `Quit`，忽略大小写及命令前后的空白。
- `Quit` 不接受参数。
- 游戏运行中的任意交互场景都可以执行 `Quit`。
- 执行成功后，整局游戏进入结束状态。
- 游戏结束后的任何命令均不再改变游戏状态。
- 游戏开始前执行 `Quit` 应被拒绝。
- 不正确的拼写、空输入和带参数的 `Quit` 不得结束游戏。

## 当前需求冲突

`大富翁User Story.xlsx` 的 A20 验收标准是“Quit 用于强制结束，整局游戏结束”。

`第一组_大富翁统一测试用例.xlsx` 的 A20 多数用例却要求“当前玩家退出、资产按破产清算、其余玩家继续”。这属于另一种功能，并依赖 A21 破产和回合切换，不是当前 A20 Story。

本项目暂以 Story 卡为准实现“结束整局”。测试组应先请 PO/老师确认，再统一修正测试用例，不能同时保留两种相反预期。
