# 大富翁集成接口文档

> 集成主干（C11）。本文档记录各模块对外接口与 Story 接入点，供后续开发（购买、过路费、升级、道具屋等）对接使用。
> 最后更新：2026-08-23

## 1. 架构总览

```
src/main.c           主循环：读命令 -> command_execute -> 输出
  └─ command_dispatcher.c   命令分发（Roll / Query / Map / Help / Quit / 引导）
       ├─ startup.c         开局引导（人数 -> 资金 -> 角色自动分配）
       ├─ quit_command.c    A20 退出
       └─ runtime.c         集成层：把 A4 + map + A8 串起来
            ├─ A4/src/a4_turn_manager.c   回合管理引擎（A4）
            ├─ map/src/map.c              地图数据（70 格）
            └─ map/src/game_interfaces.c  移动 / 骰子 / 渲染
```

- **主干**（A1/A20）：`Game` 状态机 + 命令分发 + 启动引导。
- **A4**：回合管理引擎，通过 `A4TurnHooks` 回调驱动其它模块。
- **map**（A5）：70 格地图 + 玩家 token + 移动/骰子/渲染。
- **A8**：掷骰移动逻辑，实现在 `runtime.c` 的 `roll_and_move` 回调里。

## 3. 主干接口

### 3.1 `Game`（`include/monopoly/game.h`）

```c
typedef struct {
    GamePhase phase;             /* NOT_STARTED / RUNNING / ENDED */
    GameContext context;         /* 交互场景：TURN_START / BUY_CONFIRM / ... */
    GameEndReason end_reason;
    SetupStep setup_step;        /* 引导步骤 */
    unsigned long state_revision;
    struct GameRuntime *runtime; /* 集成层运行时，NULL=引导阶段 */
    int setup_player_count;      /* 引导临时：人数 */
    int setup_initial_money;     /* 引导临时：资金 */
} Game;
```

`GameContext` 已预留落地场景枚举：`CONTEXT_TURN_START / CONTEXT_BUY_CONFIRM / CONTEXT_GIFT_HOUSE / CONTEXT_MAGIC_HOUSE / CONTEXT_HOSPITAL / CONTEXT_PRISON / CONTEXT_TOLL_SETTLEMENT`，后续 Story 可据此区分交互位置。

### 3.2 命令分发（`include/monopoly/command.h`）

```c
CommandResult command_execute(Game *game, const char *input,
                              char *message, size_t message_size);
```

已支持命令：`Roll`（掷骰移动）、`Query`（查询）、`Map`（地图）、`Help`、`Quit`。
新增命令只需在 `command_dispatcher.c` 的 `command_execute` 里加一个 `equals_ignore_case` 分支。

### 3.3 启动引导（`include/monopoly/startup.h`）

```c
StartupResult application_start(Game*, int, char*const[], char*, size_t);
CommandResult startup_handle_input(Game*, const char*, char*, size_t);
```

`startup_handle_input` 在 `runtime == NULL` 时由命令分发器调用，按 `setup_step` 依次处理：人数 → 资金 → 创建 runtime 并开始回合。

## 4. 集成层接口（`include/monopoly/runtime.h`）

```c
GameRuntime *runtime_create(int player_count, int initial_money);
void         runtime_destroy(GameRuntime *runtime);
int          runtime_begin(GameRuntime*, char *message, size_t size);
int          runtime_roll(GameRuntime*, char *message, size_t size);
int          runtime_query(GameRuntime*, char *message, size_t size);
int          runtime_render(GameRuntime*, char *message, size_t size);
int          runtime_help(GameRuntime*, char *message, size_t size);
const char  *runtime_current_player_name(const GameRuntime*);
int          runtime_is_finished(const GameRuntime*);
```

- `runtime_create`：按人数创建玩家（角色 Q/A/S/J 自动分配）、初始化 70 格地图、随机骰子、A4 回合管理器。
- `runtime_roll`：触发当前玩家掷骰移动（内部走 A4 → A8 回调）。
- 各命令入口把执行期间的提示累积到内部缓冲，最终写入 `message` 返回给 UI。

## 5. A4 回合管理接口（`A4/include/a4_turn_manager.h`）

核心类型 `A4TurnManager` + 回调集 `A4TurnHooks`：

```c
typedef struct A4TurnHooks {
    void *context;
    bool (*run_pre_roll_action)(...);         /* 卖房/路障/炸弹等掷骰前操作 */
    A4MoveResult (*roll_and_move)(void *ctx, const A4TurnSnapshot*, int forced_steps, int *actual_steps); /* A8 */
    void (*on_state_changed)(...);            /* UI 统一同步点 */
    void (*on_player_skipped)(...);           /* 住院/入狱跳过 */
    void (*on_notice)(...);                   /* 错误提示 */
    void (*on_game_finished)(...);            /* 破产/胜利 */
} A4TurnHooks;
```

常用 API：`a4_turn_manager_init / begin / roll / complete_landing / set_skip / mark_player_out / finish / snapshot`。

**关键点**：`roll_and_move` 就是 A8 的接入点，返回 `A4MoveResult`：

| 返回值 | 含义 |
|--------|------|
| `A4_MOVE_RESOLVED` | 移动+落地已完成，A4 自动切下一玩家 |
| `A4_MOVE_LANDING_PENDING` | 落地后还需交互（买地/交租），完成后调用 `complete_landing` |
| `A4_MOVE_GAME_OVER` | 移动导致游戏结束 |
| `A4_MOVE_FAILED` | 失败，A4 回滚为可再次掷骰 |

> 当前实现中 A8 落地一律返回 `A4_MOVE_RESOLVED`（自动切玩家）。若要实现「买地交互」，应改为返回 `A4_MOVE_LANDING_PENDING`，并让命令层在 `CONTEXT_BUY_CONFIRM` 场景下处理输入后调用 `a4_turn_manager_complete_landing`。

## 6. 地图接口（`map/include/map.h`、`map/include/game_interfaces.h`）

```c
#define RICH_MAP_SIZE 70   /* 70 格，0~69 */

void game_map_init(GameMap *map);
const MapCell *game_map_cell_at(const GameMap*, int index);
int  game_map_destination(int current_position, int steps);
int  game_map_cell_description(const GameMap*, int index, char *buf, size_t n);

typedef struct PlayerToken { int id; const char *name; char symbol;
                             ConsoleColor color; int position; int active; } PlayerToken;

MoveContext move_player(const GameMap*, PlayerToken*, int steps,
                        EnterCellHandler on_enter, void *user_data);

```

关键格子位置（`game_map_init` 定义）：起点 0、医院 14、道具屋 28、礼品屋 35、监狱 49、魔法屋 63、矿地 64~69。

`MapCell` 字段：`type / land_price / mine_points / owner_id / building_level / has_block / has_bomb`。

## 7. A8 掷骰移动（`src/runtime/runtime.c` 的 `roll_and_move_impl`）

流程：掷骰（`dice_roll`）→ `move_player` 移动 → 按 `cell->type` 落地处理：

| 落地格子 | 当前行为 | 待接入 |
|----------|----------|--------|
| `CELL_START` | 提示到达起点 | 经过起点发奖金 |
| `CELL_LAND`（无主） | 提示价格 | **购买流程**（见 §8） |
| `CELL_LAND`（有主） | 提示房主 | **过路费**（见 §8） |
| `CELL_HOSPITAL` | `set_skip` 住院 1 回合 | 住院 3 天等 |
| `CELL_PRISON` | `set_skip` 入狱 1 回合 | 扣留 2 天等 |
| `CELL_MINE` | `money += mine_points` | — |
| `CELL_TOOL_SHOP / GIFT_SHOP / MAGIC_HOUSE` | 仅提示 | 对应流程 |

## 8. 后续 Story 接入点

### 8.1 购买空地（无主 `CELL_LAND`）
在 `roll_and_move_impl` 的 `CELL_LAND` 无主分支：
1. 返回 `A4_MOVE_LANDING_PENDING`（而非 `RESOLVED`），并把 `game->context` 置为 `CONTEXT_BUY_CONFIRM`。
2. 命令层识别该 context 下的 `Y/N` 输入，执行扣款、`cell->owner_id = 玩家id`。
3. 调用 `a4_turn_manager_complete_landing` 结束本回合。

### 8.2 过路费（有主 `CELL_LAND`）
在 `CELL_LAND` 有主分支：`toll = land_price / 2`，扣当前玩家 `money`，加房主 `money`，置 `context = CONTEXT_TOLL_SETTLEMENT`。

### 8.3 路障 / 炸弹（A8 用例 019~021）
`move_player` 支持 `EnterCellHandler` 回调（返回 0 中断移动）。在 `roll_and_move_impl` 里传入 `on_enter` 回调，检查 `cell->has_block / has_bomb`：
- 路障：中断、`has_block = 0`；
- 炸弹：中断、`has_bomb = 0`、送医院（`set_skip`）。

### 8.4 新增命令
在 `command_dispatcher.c` 加分支，复杂命令建议新建 `src/commands/xxx_command.c` 并在此注册。

## 9. 编译与运行

```sh
cmake -S . -B build
cmake --build build
# Windows
.\build\Debug\monopoly.exe
# Linux/macOS
./build/monopoly
```

运行测试：

```sh
ctest --test-dir build -C Debug --output-on-failure
```

游戏命令：`Roll` 掷骰移动、`Query` 查询当前玩家、`Map` 显示地图、`Help` 帮助、`Quit` 退出。
