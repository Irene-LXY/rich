# A16 魔法屋接口文档

## 主工程对接

A16 使用 `include/monopoly/magic.h`，不再依赖历史版本的 `GameState` 或 `MoveResult`。玩家落到 70 格地图的第 63 格时，`GameRuntime` 打开魔法屋并向 A4 返回 `A4_MOVE_LANDING_PENDING`；施法成功或输入 `F/f` 离开后，runtime 完成落地事件并切换玩家。

命令层通过 `runtime_context()` 将 `Game.context` 同步为 `CONTEXT_MAGIC_HOUSE`，并把魔法屋输入交给 `runtime_answer()`。全局 `Quit` 始终优先处理。

## 可扩展魔法

需求没有规定具体魔法效果，因此 A16 通过 `MagicEffect` 注册扩展，不在流程层虚构规则：

```c
MagicEffect effect = {
    1,
    "具体魔法名称",
    handle_magic,
    effect_context
};

runtime_register_magic_effect(runtime, &effect);
```

回调会收到施法者下标、魔法编号、目标以及注册时的上下文。注册对象中的名称和上下文必须在 `GameRuntime` 使用期间保持有效。

## 输入规则

- 输入已注册编号：执行回调，成功后离开魔法屋；
- 输入错误编号或非数字：保持魔法屋开启，继续等待；
- 回调拒绝：保持开启，可重新选择；
- 输入 `F/f`：不施法并离开；
- 未注册具体魔法时：程序提示当前没有配置效果，玩家可输入 `F` 离开。
