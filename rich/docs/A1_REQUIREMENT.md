# A1 通过单一命令启动游戏

## 正式Story

作为繁忙玩家，为了简单快速地开一局，我希望通过单一命令启动游戏。

## 当前实现

- 单独运行一个 `monopoly` 可执行程序即可启动。
- 不接受额外启动参数；出现参数问题时明确给出正确运行方式。
- 所有启动检查通过后才一次性写入游戏状态，失败不产生半初始化数据。
- 启动后显示“玩家人数 -> 初始资金 -> 角色选择”的开局顺序，并进入玩家人数步骤。
- 每个进程持有独立的 `Game` 对象，不使用跨进程共享的全局游戏状态。
- 同一 `Game` 实例重复启动会被拒绝。

## 边界说明

操作系统在可执行文件本身缺失或C运行库无法加载时，程序代码尚未获得执行机会，因此无法由游戏内部打印错误。当前项目通过源码构建和三平台CI避免运行环境漂移，并且游戏运行不依赖额外资源文件。

角色选择和初始资金的具体输入处理分别属于A2、A3；A1只负责建立统一入口和进入引导流程。
