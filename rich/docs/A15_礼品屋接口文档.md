# A15 礼品屋接口文档

## 主工程对接

A15 使用 `include/monopoly/gift.h`，不再包含历史版本的 `roll.h`。玩家移动由 `GameRuntime` 统一管理：落到 70 格地图的第 35 格时，runtime 打开礼品屋并向 A4 返回 `A4_MOVE_LANDING_PENDING`；礼品选择结束后调用 `a4_turn_manager_complete_landing`，随后才切换玩家。

命令层通过 `runtime_context()` 将 `Game.context` 同步为 `CONTEXT_GIFT_HOUSE`，并把下一次非 `Quit` 输入交给 `runtime_answer()`。

## 礼品规则

| 输入 | 立即生效的结果 |
|---|---|
| `1` | 当前玩家资金增加 2000 元 |
| `2` | 当前玩家点数增加 200 点 |
| `3` | 当前玩家获得 5 个自身回合的财神状态 |
| 其他 | 放弃本次机会，关闭礼品屋 |

全局 `Quit` 由统一命令分发器优先处理，可在礼品屋场景直接结束整局游戏。

## 后续过路费对接

过路费模块收费前调用 `gift_shop_is_toll_free()`；返回真时免除费用。每次该玩家的回合结束时调用 `gift_shop_finish_turn()`。获得财神的当前回合不会消耗第一次数，之后持续 5 个自身回合。

`runtime_query()` 已显示资金、点数和财神剩余轮数。
