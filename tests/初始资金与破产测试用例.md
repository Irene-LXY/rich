# 初始资金与破产测试用例（A3 / A17 / A21）

前置：先完成角色选择（如 `2` → `1` → `2` → `Y`）。角色选择用例见《角色选择测试用例.md》。

## A3 初始资金设置

| 编号 | 测试内容 | 输入（资金步骤） | 预期结果 |
|------|----------|------------------|----------|
| TC-A3-01 | 默认值 | 直接回车 → `Y` | 提示“采用默认初始资金 10000 元”；确认前显示“最终采用的初始资金：每名玩家 10000 元”；两名玩家资金均为 10000 |
| TC-A3-02 | 下限边界 | `1000` → `Y` | 接受，资金均为 1000 |
| TC-A3-03 | 上限边界 | `50000` → `Y` | 接受，资金均为 50000 |
| TC-A3-04 | 低于下限 | `999` → `1000` → `Y` | 提示“999 超出范围，合法范围 1000~50000”，留在资金步骤重输 |
| TC-A3-05 | 高于上限 | `50001` → `50000` → `Y` | 提示超出范围，重输后接受 |
| TC-A3-06 | 小数 | `1000.5` | 提示“必须为纯数字整数（不支持小数、文字或其他字符）+ 合法格式与范围”，留在当前步骤 |
| TC-A3-07 | 文字 | `abc` / `一万` | 同上 |
| TC-A3-08 | 非法字符 | `10,000` / `1e3` / `+5000` / `-100` | 同上（逗号、指数、正负号均拒绝） |
| TC-A3-09 | 首尾空格容忍 | ` 30000 `（首尾空格）→ `Y` | 接受为 30000 |
| TC-A3-10 | 中间空格 | `20 000` | 判为非法格式，提示重输 |
| TC-A3-11 | 确认前显示最终数值 | 任意合法值 | 确认界面显示“最终采用的初始资金：每名玩家 X 元”与玩家人数 |
| TC-A3-12 | 取消（N） | `15000` → `N` → `20000` → `Y` | N 时提示“未修改任何玩家资金”并回到输入步骤；最终按 20000 发放 |
| TC-A3-13 | 确认环节非法输入 | `30000` → `x` → `Y` | 提示“请输入 Y（确认）或 N（重新设置）” |
| TC-A3-14 | EOF 取消 | 资金步骤直接结束输入 | 提示设置取消；程序输出“未写入任何玩家资金”后退出，无部分修改 |
| TC-A3-15 | 全部玩家资金一致 | `3` 人局，资金 `25000` → `Y` | 进入第 1 回合时三名玩家资金均为 25000 |
| TC-A3-16 | 超长输入 | 超过 120 个字符的一行（如 200 个 8） | 按截断内容校验：全数字则提示“超出范围”，含字符则提示格式错误；**不会被误判为空行采用默认值**；程序不崩溃 |

## A17 / A21 破产机制（`bin\A3_A17_A21.exe --demo` 一键演示）

| 编号 | 测试内容 | 演示场景 | 预期结果 |
|------|----------|----------|----------|
| TC-A17-01 | 交易使资金 < 0 破产 | 场景 1：玩家1 付租金 12000 | 宣布玩家1 破产（资金 -2000），状态=已破产 |
| TC-A17-02 | 破产土地归还系统 | 场景 1 | 玩家1 名下位置 6、8 均提示“归还系统，恢复为空地”，名下地产为 0 |
| TC-A17-03 | 债权人入账 | 场景 1 | 玩家2 资金 10000 + 12000 = 22000 |
| TC-A17-04 | 空地可重新购买 | 验证步骤 | 玩家2 成功购入位置 6 |
| TC-A17-05 | 资金 = 0 不破产 | 场景 2：缴费 10000 | 玩家3 资金 0，状态仍为正常 |
| TC-A17-06 | 收费（付系统）致破产 | 场景 3：缴费 25000 | 玩家2 破产（资金 -3000），位置 6 归还系统 |
| TC-A21-01 | 只剩一名玩家游戏结束 | 场景 3 后 | 宣布“只剩一名未破产玩家，游戏结束”，获胜者玩家3，游戏状态=已结束 |
| TC-A17-07 | 破产后拒绝再交易 | （代码路径） | 对已破产玩家调用 game_charge 返回 0，状态不被修改 |

## 自动化冒烟测试（Git Bash）

```bash
# 默认资金（回车采用 10000）
printf '2\n1\n2\nY\n\nY\n' | ./bin/A3_A17_A21.exe

# 非法资金输入全集 + 首尾空格容忍
printf '2\n1\n2\nY\n999\n50001\n1000.5\nabc\n20 000\n+2000\n 30000 \nY\n' | ./bin/A3_A17_A21.exe

# 边界 + 取消重设
printf '2\n1\n2\nY\n1000\nN\n50000\nY\n' | ./bin/A3_A17_A21.exe

# 破产演示（A17/A21）
./bin/A3_A17_A21.exe --demo
```
