# 帮助功能测试用例（A6）

前置：完成开局设置进入指令循环，如输入 `2` → `1` → `2` → `Y` → 回车（默认资金）→ `Y`。
也可以直接用 `bin\A6.exe --help` 不开局查看帮助。

| 编号 | 测试内容 | 输入 | 预期结果 |
|------|----------|------|----------|
| TC-A6-01 | 打开帮助 | `HELP` | 显示完整指令集界面 |
| TC-A6-02 | 忽略大小写 | `help` / `Help` / `hElP` / `HeLp` | 均显示同一帮助界面 |
| TC-A6-03 | 首尾空格容忍 | ` help `（首尾空格） | 显示帮助界面 |
| TC-A6-04 | 内容完整 | `HELP` | 含 HELP、QUERY、ROLL、STEP n、QUIT 共 5 条命令；每条含用途、参数、示例 |
| TC-A6-05 | 指令描述正确 | `HELP` | QUERY：资金/点数/房产/剩余道具/财神等状态剩余轮数；ROLL：随机 1~6 步移动；STEP n：遥控骰子指定步数、不使用随机点数；QUIT：强制结束整局 |
| TC-A6-06 | 随时、可重复打开 | 交叉输入其他内容后多次输入 `help` | 每次都正常显示帮助界面，不影响后续输入 |
| TC-A6-07 | 非整词不匹配 | `helps` / `hel` / `help me` | 不触发帮助，提示未知命令并建议输入 HELP |
| TC-A6-08 | 已知未实现命令 | `QUERY` / `ROLL` / `STEP 5` | 提示“命令 X 已识别；其功能由对应模块实现，本版本仅实现 HELP”，程序不执行对应逻辑、不崩溃 |
| TC-A6-09 | 其他命令按规范大写 | `query` / `roll`（小写） | 提示未知命令并建议 HELP（仅 HELP 忽略大小写） |
| TC-A6-10 | 空输入 | 空行 | 提示“请输入命令；输入 HELP 查看完整指令集” |
| TC-A6-11 | 未知命令 | `foo` | 提示“未知命令：foo”，建议输入 HELP |
| TC-A6-12 | QUIT 演示退出 | `QUIT` | 提示“强制结束，整局游戏结束”，指令循环退出 |
| TC-A6-13 | EOF 退出 | Ctrl+Z 回车 / 管道结束 | 提示“输入结束，退出指令输入”，程序正常结束 |
| TC-A6-14 | 不开局直查 | 命令行 `A6.exe --help` | 直接打印完整指令集后退出，返回码 0 |
| TC-A6-15 | 回归 | `A6.exe --demo` / 正常开局 | 破产演示与开局设置功能不受影响 |

## 自动化冒烟测试（Git Bash）

```bash
# 直查帮助
./bin/A6.exe --help

# 对局中：大小写变体 ×4 + 非整词 + 已知未实现 + 小写命令 + QUIT
{ printf '2\n1\n2\nY\n\nY\n'; \
  printf 'help\nHELP\nhElP\n help \nhelps\nQUERY\nSTEP 5\nquery\nQUIT\n'; } \
  | ./bin/A6.exe
# 预期：帮助界面出现 4 次；helps/query 提示未知命令；QUERY/STEP 提示已识别未实现
```
