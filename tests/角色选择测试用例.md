# 角色选择模块测试用例

运行方式：`bin/richman.exe`（或 `make run`），按下表输入并核对输出。

| 编号 | 测试内容 | 输入序列 | 预期结果 |
|------|----------|----------|----------|
| TC01 | 正常 2 人开局 | `2` → `1` → `2` → `Y` | 玩家1=钱夫人，玩家2=阿土伯；确认后创建游戏，进入第 1 回合，当前行动玩家=玩家1（钱夫人，Q） |
| TC02 | 正常 4 人开局 | `4` → `1` → `2` → `3` → `4` → `Y` | 四人依次选完，确认后进入第 1 回合 |
| TC03 | 人数下限边界 | `2` → … | 接受 2 人 |
| TC04 | 人数上限边界 | `4` → … | 接受 4 人 |
| TC05 | 人数过少 | `1` → `2` | 提示“仅支持 2~4 名玩家，请重新输入”，再次询问；输入 2 后正常继续 |
| TC06 | 人数过多 | `5` → `3` | 同上，提示后重新输入 |
| TC07 | 人数为非法字符 | `abc` → `2.5` → `（空行）` → `2` | 均提示“请输入整数形式的人数”，直到输入 2 |
| TC08 | 角色编号不存在 | 人数 `2` 后：`0` → `5` → `-1` → `1` → `2` → `Y` | 0/5/-1 均提示“不存在编号为 X 的角色”，最后正常完成 |
| TC09 | 角色编号非法字符 | 人数 `2` 后：`x` → `1a` → `1` → `2` → `Y` | 提示“请输入数字形式的角色编号（1~4）” |
| TC10 | 重复角色 | 人数 `2` 后：玩家1 选 `1`；玩家2 选 `1` → `2` → `Y` | 玩家2 选 1 时提示“已被 玩家1 选择……请从剩余角色中重新选择”；改选 2 后通过 |
| TC11 | 已选角色不出现在可选项 | 人数 `3`：玩家1 选 `2` | 玩家2 的“剩余可选角色”列表中只有 1/3/4，无 2 |
| TC12 | 显示当前操作玩家 | 任意流程 | 每次提示前均显示“当前操作：玩家N”及已完成选择进度 |
| TC13 | 确认环节按 N 重选 | `2` → `1` → `2` → `N` → `2` → `3` → `4` → `Y` | 按 N 后提示“已取消本次选择，请重新设置游戏”，回到人数输入；不产生任何玩家数据，重新选择后正常开始 |
| TC14 | 确认环节非法输入 | … → `x` → `yes` → `Y` | 提示“请输入 Y（确认）或 N（重新选择）” |
| TC15 | 中途 EOF | 直接 Ctrl+Z(回车) / 管道空输入 | 提示“输入已结束，游戏设置取消”，程序正常退出，无玩家数据 |
| TC16 | 超长输入 | 输入一行超过 120 个字符 | 视为无效输入并提示重新输入，程序不崩溃 |
| TC17 | 颜色与符号 | TC01 | 钱夫人红色、阿土伯绿色、孙小美蓝色、金贝贝黄色；符号分别为 Q/A/S/J |

## 自动化冒烟测试（Git Bash）

```bash
# TC01：正常 2 人
printf '2\n1\n2\nY\n' | ./bin/richman.exe

# TC05+TC08+TC10：人数非法 + 编号非法 + 重复角色
printf '1\n5\n2\n0\n5\n1\n1\n2\nY\n' | ./bin/richman.exe

# TC13：确认时按 N 重选
printf '2\n1\n2\nN\n3\n1\n2\n3\nY\n' | ./bin/richman.exe
```
